## 🚀 Sekilas Tentang Sistem

**Wawi Kadio System** adalah sebuah arsitektur perangkat lunak komprehensif *(End-to-End Solution)* yang memadukan operasi lini depan (Reservasi & Kasir) dengan efisiensi lini belakang (Dapur & Gudang). Dibangun di atas fondasi **Laravel 11** dan **React 18** *(Single Page Application)*, sistem ini menawarkan kecepatan tanpa *loading* ulang halaman berkat teknologi **Inertia.js**.


## 🚀 Panduan Instalasi Lokal (Developer Guide)

Ikuti instruksi komprehensif ini untuk menyiapkan lingkungan pengembangan web *(Localhost Development)* pada komputer Anda.

### 1. Persiapan Awal
Buka terminal Anda dan lakukan kloning repositori GitHub ini, kemudian masuk ke dalam direktorinya:
```bash
git clone https://github.com/Yersolid07/wawi_kadio_sc.git
cd wawi_kadio_sc
```

### 2. Menginstal Seluruh Mesin Penggerak
Sistem membutuhkan instalasi pustaka bergantung dari sisi peladen (PHP) dan antarmuka (Node.js):
```bash
composer install
npm install
```

### 3. Konfigurasi Lingkungan (`.env`)
Buat file kunci rahasia (*Environment*) dari *template* awal yang telah tersedia, lalu *generate* kuncinya:
```bash
cp .env.example .env
php artisan key:generate
```
*(Catatan: Segera buka file `.env` di teks editor, lalu sesuaikan koneksi `DB_DATABASE`, `DB_USERNAME`, dan `DB_PASSWORD` sesuai dengan MySQL lokal Anda / XAMPP).*

### 4. Bangun Database & Tautkan Storage Aset
Perintah ajaib ini akan menciptakan semua tabel sekaligus menanamkan Data *Dummy*, Menu, Fasilitas, dan Kredensial Pengguna. Jangan lupa tautkan folder *storage* agar gambar muncul:
```bash
php artisan migrate --seed
php artisan storage:link
```

### 5. Kompilasi Aset Frontend React
Gunakan perintah *build* agar kode React diterjemahkan menjadi Javascript/CSS ringan:
```bash
npm run build
```

### 6. Jalankan Server Paralel
Buka **dua jendela terminal terpisah** untuk menyalakan mesin *backend* dan *hot-reload frontend*:

**Terminal 1 (Backend PHP):**
```bash
php artisan serve
```

**Terminal 2 (Frontend HMR):**
```bash
npm run dev
```
🌐 Buka `http://localhost:8000` di *browser* Anda. Situs sudah sepenuhnya beroperasi! 🎉

## 🔒 Panduan *Deployment* Ketat ke Server (Production)

Perhatian! Proyek ini telah lulus *Security Audit* penuh, pengujian 100% *Test-Driven Development (TDD)*, dan siap diterjunkan untuk skala industri (*Production Ready*) di **VPS, CPanel, AAPanel, atau layanan Cloud lainnya**. 

Sebelum sistem Anda rilis dan diakses oleh ratusan pelanggan asli, Anda **Wajib Mutlak** menjalankan urutan perintah optimalisasi berikut di terminal server Anda:

```bash
# 1. Pindah ke direktori utama website Anda
cd /var/www/wawikadio

# 2. Instalasi Murni Tanpa Paket Development (Meringankan Beban RAM Server)
composer install --optimize-autoloader --no-dev
npm ci

# 3. Compile Aset React Menjadi File Statis Super Cepat
npm run build

# 4. Optimasi Ekstrim Laravel Cache (Menghilangkan waktu muat/Load Time)
php artisan optimize:clear
php artisan config:cache
php artisan event:cache
php artisan route:cache
php artisan view:cache

# 5. Sesuaikan Hak Akses agar Server bisa Menyimpan Foto / PDF
chown -R www-data:www-data storage bootstrap/cache
chmod -R 775 storage bootstrap/cache
```
